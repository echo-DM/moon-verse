## 2026-09-25：连续世界重构

- 七处景点始终存在于同一个世界，诗句只控制镜头目的地。
- 添加共享湖岸、石径、远山与固定月亮；添加俯瞰全境入口。
- 移除定时切景与淡出遮罩，改为可中止、可重新选择目的地的镜头飞行。
- `pnpm build` 通过 TypeScript 检查及 Vite 生产构建；三维包仍有超过 500 KB 的体积提示。
- 本轮未运行浏览器交互测试或性能测试，也未更新截图。下方验收结果仅适用于重构前版本，不能作为当前版本的浏览器验收依据。

## 历史记录：独立场景版本

验收对象：本地生产构建，`pnpm preview`；浏览器为 agent-browser 启动的 Chromium。

## 已验证

- `pnpm build`：TypeScript 检查与 Vite 生产构建通过。
- 1280×800、1440×900、1920×1080 桌面视口：无水平溢出，诗文与底部导航不重叠。
- 七幕均能通过真实按钮点击进入；当前幕标题与实际场景一致，转场正常结束。
- 快速依次点选 01 → 05 → 03 → 07 → 02：最终停在 02，界面与景观一致，没有转场堆积。
- 全词面板覆盖正文七个分段；点击末段可进入“千里婵娟”，面板自动关闭；Esc 可关闭面板。
- 鼠标拖动、滚轮缩放、恢复最佳视角、进入/退出全屏均正常。
- 暂停环境动态后，相隔 1.2 秒的两张截图 SHA-1 完全一致；拖动和缩放后的截图发生变化。
- 系统减少动态效果开启时，点击诗句立即切换且不进入转场；相隔 1.5 秒的两张截图 SHA-1 完全一致。
- 独立会话通过 `WEBGL_lose_context` 扩展模拟上下文丢失：显示可读回退提示，加载遮罩消失，“读全词”仍可打开。
- 最终正常生产会话：页面错误列表为空，控制台消息列表为空。

## 边界与构建提示

本次按要求只验收电脑网页。浏览器测试未覆盖所有品牌显卡和其他浏览器引擎，未进行线上部署。三维模块为独立延迟加载包，约 918 KB / gzip 249 KB；Vite 会给出超过 500 KB 的包体积提示，构建成功。初次加载字体需要访问 Google Fonts，失败时自动使用本地宋体。

开发期间修正了首幕相机提前停止和入口热更新重复挂载的问题；最后的生产验收使用独立浏览器会话，不沿用开发期间的错误记录。
