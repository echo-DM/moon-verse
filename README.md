# 月境 · Moon Verse

以苏轼《水调歌头·明月几时有》为线索的 React / Three.js 交互网页。同一个完整的体素世界，七处诗句取景点，从把酒问天走到千里婵娟。

面向电脑浏览器，建议窗口宽度至少 1024px、高度至少 740px。需要支持 WebGL 2 的现代浏览器。

## 本地运行

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址。生产构建及本地预览：

```sh
pnpm build
pnpm preview
```

## 观景

- 点击底部诗句，镜头在同一片山河的七个地点之间飞行；前后箭头顺序导航。
- 右侧地图按钮“俯瞰全境”查看整体布局，再次点击回到当前诗句。
- 镜头先升高、越过湖面，再靠近目的地，全程可见；途中点选另一句会从当前位置重新出发，拖动或滚轮可以中止飞行。
- 鼠标拖动环顾，滚轮缩放；右侧回转箭头恢复该幕的最佳视角。
- 暂停按钮停止水纹、流云、舟行与人物等动态；全屏按钮扩展观景区域。
- “读全词”展开完整原词，点击任一段可跳转到对应场景；Esc 关闭面板。
- 遵循系统“减少动态效果”设置，停用转场和环境动画。

## 实现

React + TypeScript + Vite，使用 React Three Fiber、Drei、Three.js 和 Lucide。建筑、山石、树木、人物与水纹均为程序化几何，无外部模型或图片素材。重复方块使用 InstancedMesh，共享每批几何和材质；采用抗锯齿、月色照明、阴影和距离雾，无像素化滤镜。

- `src/chapters.ts`：诗句分段、文案、七处相机位置与全境视角。
- `src/World.tsx`：共享地形、固定景点布局、环境动画与镜头飞行控制。
- `src/App.tsx` / `src/style.css`：桌面界面、导航、全文阅读与布局。

字体优先使用 Google Fonts 的 Noto Serif SC，网络不可用时退回本地宋体。诗中宫阙、庭院、桥与舟为艺术演绎。所有景点始终挂载在同一个世界坐标系中，共用地形、水面、月亮、远山和照明。切换诗句只修改镜头目的地，不替换几何或移动月亮；首次打开会单独加载三维渲染模块。

地面景观沿湖岸与石径连接，宫阙位于北侧高空。“减少动态效果”直接定位到取景点；暂停景物动态不影响主动导航。所有地点同时渲染会比旧版单幕模式增加 GPU 负担。
